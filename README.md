# Anomaly Detection for Fraud and Sensor Data

## Summer Internship 2026 Project

### Objective

The objective of this project is to identify anomalous transactions using statistical and machine learning based anomaly detection techniques.

### Techniques Used

* Z-Score Anomaly Detection
* Interquartile Range (IQR) Method
* Isolation Forest
* Local Outlier Factor (LOF)

### Features

* amount
* hour_of_day
* transactions_last_24h
* distance_from_home_km

### Workflow

1. Generate synthetic transaction dataset
2. Analyze class distribution
3. Compare feature means
4. Detect anomalies using Z-Score
5. Detect anomalies using IQR
6. Train Isolation Forest model
7. Evaluate Isolation Forest
8. Train Local Outlier Factor model
9. Evaluate LOF model
